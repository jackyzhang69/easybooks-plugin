# EasyBooks — what changed in this version

This release can connect with Jacky's assistant for a short, confirmed live
session when you have a join code. Recording expenses, importing receipts,
creating invoices, and Gmail import work the same as before: dry-run, confirm,
then write. Sign-in and Tell Jacky are unchanged. After an update, the agent
briefly explains what changed and continues your prior request without making
you repeat it.
